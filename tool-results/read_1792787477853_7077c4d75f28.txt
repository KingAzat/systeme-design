   140→### Contrat simulation-store (implémenté par 4-a, consommé par 4-b) :
   141→```ts
   142→interface SimulationState {
   143→  status: "idle" | "running" | "done" | "error";
   144→  progress: SimulationProgress | null;
   145→  error: string | null;
   146→  result: SimulationResult | null;
   147→  run(arch: ArchitectureData, architectureId: string | null): Promise<void>;
   148→  abort(): void;
   149→  reset(): void;
   150→}
   151→```
   152→`run()` : passe status running (progress via onProgress), exécute `runSimulation` de `@/engine`, sur succès : enrichit le résultat (id=shortId, architectureId réel ou "local"), persiste un SimulationRecord via `storage.simulations.create` (best-effort si architectureId non null), appelle `useAppStore.getState().openResult(result)` et refreshSimulations(), status done. Sur AbortError → status idle sans erreur. Sur autre erreur → status error + message.
   153→"Relancer" depuis résultats : `run({ name: r.architectureName, nodes: r.snapshot.nodes, edges: r.snapshot.edges, zones: r.snapshot.zones, scenario: r.scenario }, r.architectureId !== "local" ? r.architectureId : null)`.
